Scope: Implement a deterministic, idempotent, headless export-citation builder in the case-box-persistence package that realizes the A3-EXPORT-00 export-degradation contract. The builder FIRST runs the existing resolver `resolveLinkStatuses(db, { tenant_id, matter_id })` to refresh case_box_links.status for the scope (the ONLY write), then derives — read-only — a deterministic export-citation object per link: linkStatus (valid|needs_review|broken) + exportFlag (BROKEN|NEEDS_REVIEW|NON_CITABLE|AMBIGUOUS|null) + the DocumentPage-derived 卷X页Y citation when safely available. It does NOT fork independent validity rules (resolver status is the source of truth). It preserves citation trust: a stale/unresolved/missing anchor MUST never export as a silently-valid citation. NO schema change, NO migration, NO export-file rendering, NO UI/product behavior, NO anchor-delete/cascade policy, NO full Evidence document lifecycle, NO dependency, NO marker/key/gate change. NO audit events (deferred). NO REPLACED refinement (deferred unless review-plan identifies a named reason source already present and keeps it in scope).
Required decisions to record: (1) ENTRY POINT — a headless `buildExportCitations(db, { tenant_id, matter_id })` (or a review-plan-approved package-convention equivalent) following existing case-box-persistence conventions; callable with a db handle + tenant/matter scope; no network, no production-evidence ingestion, no encryption/key management. (2) RESOLVER-FIRST — the builder MUST call resolveLinkStatuses(db, { tenant_id, matter_id }) BEFORE deriving citations for that scope (A3-EXPORT-00 §6); it MUST NOT fork its own validity computation; the refreshed case_box_links.status is the trusted source. The resolver's status refresh is the ONLY write; export-object generation is read-only after it. (3) INPUTS — case_box_links (status + source identity + anchor_id), case_box_anchors, case_box_document_pages (V9 — incl. the citation-identity fields kept in payload_json), case_box_document_page_geometries (V10), and the document/page citation-identity fields available today. (4) CITATION IDENTITY RECONCILIATION — the human-facing citation fields (citationVolume / citationPageLabel / isCitable / citationPageSortKey) live in the V9 case_box_document_pages.payload_json (schema.ts header note, user decision 2026-06-24; handover §A1), NOT in dedicated columns and with NO formal contract type today. The builder reads them from payload_json. A page is citable only when payload_json carries a usable citationVolume + citationPageLabel AND isCitable !== false. (5) EXPORT-FLAG DERIVATION (A3-EXPORT-00 §3 precedence; exactly one flag per link) — linkStatus broken -> exportFlag BROKEN (no 卷X页Y / rect claim; best-effort source + best-effort document/page identity when the anchor row exists); linkStatus needs_review -> exportFlag NEEDS_REVIEW (DocumentPage identity + label preserved best-effort when available, but flagged review-required, NEVER a clean citation); linkStatus valid -> a clean citation (exportFlag null, 卷X页Y from DocumentPage identity) ONLY if the page is citable (decision 4) AND the citation label is unambiguous; else valid -> AMBIGUOUS (the (citationVolume, citationPageLabel) maps to >1 physical page in the link's document scope — A1: disambiguate or refuse+warn, never guess) or NON_CITABLE (no usable citation identity / isCitable false). (6) VALID NECESSARY-NOT-SUFFICIENT — a valid link is necessary but NOT sufficient for a clean citation; if page/citation identity cannot be emitted safely, the builder emits AMBIGUOUS or NON_CITABLE (A3-EXPORT-00 §3 review-L1), never a clean citation; a valid link MUST NEVER produce REPLACED. (7) REPLACED DEFERRED — do NOT implement the REPLACED refinement in this WI; needs_review -> NEEDS_REVIEW by default. Only if review-plan identifies a named reason source already present AND explicitly keeps it in scope may REPLACED be derived; otherwise STOP and report if review-plan demands it. (8) A10 NO-DROP — a missing page/geometry/anchor MUST produce a deterministic BROKEN export object (preserving link/source identity, empty citation), NEVER a silent omission; every in-scope link yields exactly one export-citation object. (9) GEOMETRY / IDENTITY — citation identity comes only from DocumentPage; the builder MUST NOT use an OptimizedDocumentRendition as canonical and MUST NOT use viewport/rendered coordinates as citation identity. (10) OUTPUT CONTRACT — a deterministic export result: an ordered (by link id) array of export-citation objects { linkId, sourceType, sourceId, documentId?, physicalPageIndex?, linkStatus, exportFlag, citation? (citationVolume + citationPageLabel + the 卷X页Y text when clean), } + an optional summary count by exportFlag. Object names stable + test-covered. Determinism + idempotence: same DB state + scope -> identical objects; a repeated call writes nothing beyond the (idempotent) resolver refresh. NO audit events (deferred).
