## WI-PKG1: packaging — fix electron-builder asar bloat (directories.output + narrowed files)
Type: IMPL
Scope: Make `npm --prefix apps/lawbar-desktop run dist` produce a distributable by tightening electron-builder packaging INPUTS only. Build-config + validation; NO app runtime / DPE / dependency change. ROOT CAUSE (locked): `directories.output` defaulted to `dist` (the same dir as the TS build output `main: dist/electron/main.js`), so electron-builder wrote `dist/mac/lawbar.app` (measured 4.3GB) INTO `dist/`, and `files: ["dist/**/*", "package.json"]` then made the next run recursively re-pack that prior `dist/mac/lawbar.app` into the new app.asar → `app.asar: file size cannot be larger than 4.2GB`. This is a packaging input/output COLLISION, not a runtime or DPE regression (devDependencies electron/app-builder-bin/playwright/typescript are already excluded by electron-builder; the real app code under dist/electron 40KB + dist/renderer 29MB is tiny). FIX SHAPE (locked): (a) PRIMARY — set the electron-builder `directories.output` to `release` (already gitignored) so packaging output leaves the `dist/**` input tree; (b) DEFENSIVE — narrow `files` from `dist/**/*` to an ALLOWLIST of the real app runtime inputs (dist/electron/**, dist/renderer/**, and dist/src/** only if the dist/electron/main.js require-graph needs it, + package.json) plus exclude `**/*.js.map` and `dist/builder-*.{yml,yaml}`; do NOT rely SOLELY on negating dist/mac*. Keep `better-sqlite3` native handling via the existing `asarUnpack: ["**/node_modules/better-sqlite3/**"]` unless review-plan proves a different pattern (e.g. extraResources) is needed. The edit is confined to the `build` field of apps/lawbar-desktop/package.json. `.gitignore` is NOT touched (release/ is already ignored).
Source of truth: dev-memo/plan-batch-desktop-packaging-asar-fix-00.md (the plan, §0 locked decisions); the measured packaging inputs (dist/mac=4.3GB, dist/mac-arm64=257MB, dist/electron=40KB, dist/renderer=29MB; node_modules devDeps electron 247MB/app-builder-bin 207MB excluded); apps/lawbar-desktop/package.json (the inline electron-builder `build` field: appId io.lawbar.desktop, productName lawbar, mac.target dir arm64+x64, mac.identity null, files ["dist/**/*","package.json"], asarUnpack ["**/node_modules/better-sqlite3/**"]); apps/lawbar-desktop/.gitignore (dist/, release/, dist-tarballs/ all already ignored); AGENTS.md §"Test-environment notes" (dist rebuilds better-sqlite3 for the mac.target arches; postdist `electron-builder install-app-deps` restores the host binding on success; a failed dist skips postdist); dev-memo/plan-desktop-package-architecture-00.md + plan-packaging-smoke-00.md + plan-desktop-pkg-arch-tarball-poc-01.md (the file:dist-tarballs/*.tgz internal-package coupling, OUT of scope); scripts/test-packaged-wrapper.mjs (packaged-test harness).
