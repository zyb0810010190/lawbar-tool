Type: IMPL
Scope: Implement A0.7 marker WRITE + keyed marker VALIDATION + a guard-owned ledger, per ADR A07-MARK-00, with markers as LOCAL-ONLY run-state (gitignored; never committed — user storage decision). Components: (a) a marker writer scripts/workflow/a07-marker-write.sh that runs the existing A0.7 harness, requires status=pass AND classification=ok, builds the canonical marker payload, computes provenancePayloadHash (sha256 of the canonical payload), computes an HMAC over the canonical payload using the ENV-supplied key, writes a local marker JSON under dev-memo/run/evidence/a07/, and appends a guard-owned ledger entry binding runId -> {markerPath, provenancePayloadHash, repoCommit, repoTreeHash}; (b) a minimal Swift executable target (native/evidence-core-swift) that runs EvidenceCoreA07Harness.run and prints the deterministic result so the writer reuses the real harness (not a re-implementation); (c) extend scripts/workflow/check-marker-guard.sh so --staged and the default commit/scan-of-TRACKED paths still reject ALL dev-memo/run/evidence/** material UNCONDITIONALLY (committed markers never allowed), while --scan of LOCAL (untracked working-tree) markers VALIDATES them: accept only a genuine marker (env key present + recomputed provenancePayloadHash matches + HMAC verifies + fixture/oracle sha still match + ledger binds runId->path+payloadHash+repo/tree); reject fabricated/copied/touched/schema-only markers; the guard's own ledger file is skipped (not treated as a marker); if env key/ledger unavailable, validation fails closed for that local marker.
