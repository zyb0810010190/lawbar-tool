## WI-A3-EXPORT-00: export-degradation design (design-only; NOT A0.7-gated)
Type: PLAN
A0.7-classification: A3-EXPORT-00 is design-only and intentionally NOT A0.7-gated. This docs-only ADR/plan SPECIFIES how exports degrade when a link is needs_review/broken (the ExportCitationFlag semantics) BEFORE any export implementation; it implements no export code, no schema/migration, no UI, and changes no gate/marker behavior, so it needs no live provenance-valid A0.7 marker. Therefore this WI carries NO `Requires-A07:` line. The FUTURE export implementation WI MUST declare `Requires-A07: yes` (custody mode 9b). review-plan must confirm this classification; if review-plan says this docs-only WI must be A0.7-gated, STOP and report.
Scope: Define how court-fileable exports degrade when an A3 link resolves to needs_review or broken, preserving citation trust (no unresolved/stale anchor may appear as silently-valid evidence), BEFORE any export implementation. Specify the deterministic export-citation degradation contract (the ExportCitationFlag set + the minimal headless export-citation object shape) grounded in the merged V9-V11 schema, the resolved case_box_links.status (resolver = source of truth), the A1 citation-from-DocumentPage identity, and the A10 export-reproducibility invariant. Design/ADR ONLY — no code, no schema/migration, no UI, no export implementation, no anchor-delete cascade resolution, no full Evidence document lifecycle schema, no dependency, no marker/key/gate change. Output: docs/adr/ADR-evidence-a3-export-degradation.md (A3-EXPORT-00) + dev-memo/plan-batch-casebox-evidence-a3-export-degradation-00.md; an optional additive cross-reference to the resolver/schema ADRs only if review-plan recommends it.
Required decisions to record: (1) EXPORT INPUTS — case_box_links.status (the resolver output; source of truth), case_box_anchors, case_box_document_pages (V9), case_box_document_page_geometries (V10), and the document/page citation-identity fields available today (DocumentPage identity: documentId + physicalPageIndex -> the citation volume/page label kept in payload_json; A1). (2) VALID LINK EXPORT — a valid link may export a normal 卷X页Y citation ONLY if all citation identity resolves; the citation MUST be derived from the document/page identity (A1 DocumentPage), NEVER from viewport/rendered/optimized coordinates. (3) needs_review EXPORT — export MUST NOT silently present stale geometry as trusted; define a visible degradation flag (e.g. ExportCitationFlag.NEEDS_REVIEW / 引用待核_NEEDS_REVIEW); the exported citation SHOULD preserve the stable document/page identity when available but MUST be marked review-required. (4) broken EXPORT — export MUST NOT produce a normal citation; define a visible degradation flag (e.g. ExportCitationFlag.BROKEN / 引用缺失_BROKEN); export SHOULD preserve best-effort source/link identity if available but MUST NOT claim page/rect validity. (5) MISSING page/geometry/anchor BEHAVIOR — define a deterministic fallback text/data shape (no silent omission unless explicitly chosen + justified). (6) GEOMETRY — exports MUST NOT use an OptimizedDocumentRendition as canonical; exports MUST NOT recompute validity from geometry independently — the resolver status (case_box_links.status) is source of truth unless the implementation WI explicitly recomputes via the SAME resolver first. (7) ORDERING — define whether export MUST run the resolver first or MAY require the caller to run the resolver before export; if unresolved, PREFER: the implementation WI runs a resolver/status refresh immediately before export in the same matter/document scope. (8) AUDITABILITY — decide whether export degradation writes audit events now or defer; if the audit-event shape is unclear, DEFER and record it as a future WI (do not invent an audit shape here). (9) OUTPUT CONTRACT — define a minimal headless export-citation object shape (include status/flag, page identity, source identity); do NOT design UI copy beyond the export-text semantics necessary for the contract. (10) A0.7 GATING — this design-only WI is NOT A0.7-gated; the future export implementation WI MUST declare Requires-A07: yes (custody 9b).
