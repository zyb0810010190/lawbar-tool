The fix requires a new WI because WI-701 is merged + closed. **Recorded** in `dev-memo/deferred-audit-findings.md` (CBW-UI-701-DEFAULT-PURPOSE). **Suggested follow-up**: a bounded WI-703 — mark the `"other"` option `selected` (or omit `purpose` when unchanged so the server applies its own `"other"` default) + a browser-faithful default-value test asserting an unchanged submit forwards `"other"` (or omits purpose).
