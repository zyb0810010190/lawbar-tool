## Why an oracle-free mode existed to be built

A0.7's real question is whether the geometry SOURCE is reproducible, not whether it equals a stored
oracle. Oracle mode could not be pointed at real-world documents at all: generating an oracle from a real
filing would persist client-derived page dimensions to disk, which is not permitted by default. A
stability check needs no oracle, so the confidentiality question never arises — that is what finally let
the gate be exercised against real material.
