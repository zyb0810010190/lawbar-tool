### Deferred finding (recorded in dev-memo/deferred-audit-findings.md)
- **UISHELL-L1 (Low)**: the static shell hardcodes `aria-current="page"` on the `#/matters` sidebar
  link, so on `#/matters/new` assistive tech still announces "Matters" as the current page.
  No security/architecture/data-correctness impact; navigation + keyboard reach are correct.
  **Deferred**: a correct fix is dynamic (drive `aria-current` from the active route in
  `renderer/index.ts`), which is renderer-JS scope outside this merge run's delegation. Target: the
  next renderer UI PR (detail/create rework already touches route handling) or a one-line a11y
  follow-up, plus a shell-test assertion that exactly one sidebar link is current per route.

## Decisions
- **Full design-system integration in one CSS step** (vs rule-by-rule across PRs): integrating the
  complete editorial + shell stylesheet once, then wiring each screen's DOM per later PR, avoids
  re-editing `index.css` six times and cascade drift. Falsifier: if inert future-screen selectors
  cause visual regressions on live screens before their PR lands. Audited as Low (inert).
- **`cn-overlay`/`v12` `:root` blocks NOT ported**: would create a 3rd `:root` block, breaking the
  no-hardcoded-color lint's exactly-2 invariant + the palette-sync-locked scale. The `html` font
  vars already prioritise self-hosted Noto SC, so nothing is lost.
