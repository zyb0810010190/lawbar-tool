# UI baseline pointer

Before any future UI Work Item, read the legacy UI baseline record at
[`dev-memo/ui-baseline.md`](ui-baseline.md).

That record is the source of truth for what UI already exists (the desktop renderer, theme
tokens, and renderer/UI tests) and is treated as **legacy baseline evidence, not new
autonomous UI work**. Per `dev-memo/ui-baseline.md`, UI Work Items remain deferred: `Type: UI`
is not enabled, and a UI WI must carry a Claude Design artifact before it can enter a governed
queue. This pointer exists so future UI work starts from that baseline rather than re-deriving
it.
