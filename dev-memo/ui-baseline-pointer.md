# UI baseline pointer

Before any future UI Work Item, read the legacy UI baseline record at
[`dev-memo/ui-baseline.md`](ui-baseline.md).

That record is the source of truth for what UI already exists (the desktop renderer, theme
tokens, and renderer/UI tests) and is treated as **legacy baseline evidence, not new
autonomous UI work**. Per `dev-memo/ui-baseline.md` (updated 2026-06-02), `Type: UI` **is** now
enabled for governed-queue entry but requires a concrete `Design artifact:` reference (the
design-artifact gate is built; full UI automation remains deferred). This pointer exists so
future UI work starts from that baseline rather than re-deriving it.
