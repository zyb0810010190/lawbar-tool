## The two survivors — the whole point of this exercise

Line coverage of both scripts was **100%**, and it still missed both of these. Coverage proves
a line ran; only mutation proves a test would object if the line changed.

### M03 — the `^` anchor was unpinned

Removing the leading anchor from `has_developer_id` left all 93 tests green. Diagnosis:
`PHRASE_IN_TRAILER_ONLY`, the fixture T3.11 uses, is rejected by the **row shape**
(`N) HEX "…"`), not by the anchor — there is no identity-row shape anywhere in it, mid-line
or otherwise. So T3.11 pins row-shape, and nothing pinned the anchor.

Closed by **T3.12**: a fixture satisfying every other clause of the regex — numbered marker,
all-hex hash, quoted Developer ID name, line ending at the closing quote — with the shape
appearing **mid-line**. Only `^` rejects it. Verified to fail against the M03 mutant.

### M18 — the Developer ID authority check was unpinned

Replacing the `Authority=Developer ID Application:` probe with an unconditional `devid=1`
left all 93 tests green. Diagnosis: every existing green-path case already carried Developer
ID authority, so no case distinguished "Developer ID signed" from "signed by anything".
The script could stop making that distinction and the suite would not notice — and that
distinction is precisely what makes exit 0 mean *release-ready*.

Closed by **T8.20**: a bundle signed by `Apple Development:` (not adhoc, deep-strict passes,
Gatekeeper accepts, ticket validates) must be verdict **2**, never 0 and never 3. Verified to
fail against the M18 mutant.
